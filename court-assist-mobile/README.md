# Court Assist mobile

This is the Expo SDK 58 app for Court Assist. Follow the [root setup guide](../README.md) for environment configuration, backend startup, and Android development builds.

```powershell
Copy-Item .env.example .env
npm ci
npx expo start
```

Use `npm run typecheck` and `npm run lint` for local checks. The app uses a native development build for its native modules.
